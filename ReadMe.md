# VACAC Modular Conveyor System

A modular conveyor-building prototype created in Unity 6.6 for the VACAC Graduate Software Engineer technical task.

## Repository

Repository URL will be added after the GitHub repository is created.

## Current features

- Three modular conveyor types
- Runtime conveyor selection and placement
- Rotation before placement
- Forward conveyor snapping
- Conveyor movement paths

## Controls

- `1` — Select generic conveyor
- `2` — Select short conveyor
- `3` — Select incline conveyor
- `R` — Rotate preview
- Left mouse button — Place conveyor

## Unity version

Unity 6.6
